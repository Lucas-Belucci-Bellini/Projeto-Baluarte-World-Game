# 81 — Stack e ferramentas

## Web (atual)
- **JS puro (ES2022) + HTML5 + CSS3 + Vite 5** — igual ao `Projeto-Baluarte`.
- Sem framework, sem TypeScript (alinhado à plataforma-mãe).
- Testes em Node puro (`node --test`/script próprio); ver [`../tests/`](../tests/).

## 3D (futuro, condicional)
- **Unreal Engine** (D-03) para Eras 3–5 se houver recursos/arte.
- Dados reaproveitados como DataTables (ver [82](82-dados-e-datatables.md)).

## Por quê
Web-first dá protótipo rápido, joga no navegador (escola) e integra com o
Baluarte. 3D só quando a mecânica fechar e o escopo justificar.

## Ferramentas de apoio
Git (versionamento por branch + main — ver [91](91-versionamento-e-branches.md)),
JSON para conteúdo, freesound/CC para áudio.
