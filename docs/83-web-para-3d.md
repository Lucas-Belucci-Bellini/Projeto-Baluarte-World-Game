# 83 — Da web para o 3D

Como uma Era pode "subir" de protótipo web para 3D sem jogar trabalho fora.

## O que migra de graça
- **Dados** (JSON → DataTables): receitas, itens, módulos, missões.
- **Regras** (pontuação/economia): a matemática é a mesma; só muda a apresentação.
- **Balanceamento** validado no protótipo web.

## O que se refaz
- Render (DOM → 3D), input, arte/áudio finais.

## Critério para migrar
Só migra Era cuja **mecânica já fechou** na web e cujo valor 3D justifica o
custo. Protótipo web continua válido (escola/sem instalar).

## Verificação cruzada
Web e 3D devem dar **a mesma pontuação** para a mesma sequência (como já exigimos
da Era 0). Ver [93](93-definicao-de-pronto.md).
