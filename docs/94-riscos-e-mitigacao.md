# 94 — Riscos e mitigação

| Risco | Mitigação |
|-------|-----------|
| **Escopo explode** (9 jogos!) | Este GDD é o filtro; uma **Era por vez**, cada uma fecha sozinha. Teto por Era (ver [84](84-performance-e-orcamento.md)). |
| **Virar cópia** (legal) | **Regra de ouro**: ideias, não arquivos (ver [04](04-regra-de-ouro-ideias-nao-arquivos.md), [95](95-licencas-e-referencia-limpa.md)). |
| **Equipe de 1** | Fatias pequenas e independentes; nada exige "o jogo inteiro". |
| **Peso 3D / performance** | Web-first; 3D só quando justificar e com teste cedo. |
| **Perder progresso** | Versionamento por branch + main (ver [91](91-versionamento-e-branches.md)). |
| **Educacional se perder** | Era 0 nunca regride; é critério de pronto (ver [93](93-definicao-de-pronto.md)). |
| **Motivação/foco** | Roadmap-mestre visível; cada Era é uma vitória demonstrável. |
