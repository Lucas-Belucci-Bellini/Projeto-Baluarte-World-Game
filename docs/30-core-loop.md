# 30 — Core loop

O loop básico que se repete e escala em todas as Eras.

## O loop (micro)
1. **Coletar** sucata/recursos do mundo.
2. **Processar/triar** (na mão → automatizado).
3. **Aplicar** (craftar, construir, alimentar a cidade).
4. **Crescer** (mais alcance, mais produção, mais população).

## O loop (macro)
Sobreviver → Automatizar → Urbanizar → Defender → Decidir. Cada volta abre a
próxima Era. Ver [20](20-eras-visao-geral.md).

## O gancho moral
Cada volta premia o **ciclo fechado**: fechar o ciclo gera mais recurso/EcoPonto
que queimar/aterrar. Ver [31](31-economia-circular-e-recursos.md).

## Sessão ideal
3–10 min na Era 0; sessões mais longas e abertas nas Eras seguintes, sempre com
um objetivo visível e uma "vitória de setor/colônia".
